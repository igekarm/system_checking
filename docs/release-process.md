# Публикация нового релиза

Релиз выполняется из корня публичного репозитория одной командой:

```powershell
cd D:\system_checking_public
.\release.cmd 0.1.8 "Add Oracle Database provider"
```

Сценарий автоматически:

1. проверяет ветку `master` и получает изменения через fast-forward;
2. запускает `npm.cmd ci` — это не зависит от PowerShell Execution Policy;
3. выполняет тесты и production-сборку;
4. добавляет изменения только из `JS_project`, `.github/workflows`, `scripts`, `docs` и `release.cmd`;
5. создаёт коммит, если есть новые изменения;
6. отправляет `master` и проверяет синхронизацию с GitHub;
7. проверяет уникальность тега `app-vX.Y.Z`, создаёт его и запускает release workflow.

Если изменения уже закоммичены и отправлены, сценарий не создаёт пустой коммит, а выпускает текущий `master`.

Допустим только формат версии `X.Y.Z`. Суффиксы вроде `0.1.8a` намеренно запрещены workflow.

Сценарий останавливается до создания тега при ошибке установки зависимостей, тестов, сборки, синхронизации Git или проверке версии.

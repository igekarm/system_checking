# История изменений DB Tools

## 0.1.5

- Добавлен безопасный технический журнал приложения и обновлений.
- Версия приложения отображается в интерфейсе и настройках.
- После первого запуска новой версии показывается окно с описанием изменений.
- Проверка и загрузка обновлений из публичных GitHub Releases больше не требуют авторизации пользователя.

Перед выпуском следующей версии добавьте новый раздел в начало этого файла. Не включайте сюда SQL, сведения о подключениях, пароли или другие конфиденциальные данные.

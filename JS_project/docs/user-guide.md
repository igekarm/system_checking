# DB Tools MVP — руководство проверки

## Поддерживаемая платформа

Windows 10/11 x64 и PostgreSQL. Другие СУБД пока не включены. Приложение не требует установленного Node.js.

## Подключение

Откройте вкладку **Подключения**, нажмите `+`, заполните сервер, порт, базу, пользователя и пароль. Режим **Предпочитать SSL** сначала пробует SSL, а если сервер явно не поддерживает SSL — автоматически повторяет без него. **Проверить** открывает реальное соединение и выполняет безопасный запрос сведений о сервере. **Сохранить** записывает профиль без пароля в пользовательскую директорию; пароль хранится отдельно в зашифрованном виде через Windows DPAPI/Electron safeStorage.

При редактировании пустое поле пароля сохраняет прежний пароль. Удаление подключения удаляет и секрет.

## SQL

Выберите подключение, введите один SQL statement и нажмите **Выполнить**. Timeout и лимит строк задаются в настройках. Результат читается серверным cursor, поэтому приложение не загружает таблицу целиком. **Отменить** вызывает `pg_cancel_backend`; при ошибке отдельного cancel-соединения рабочее соединение закрывается.

Каталог запросов находится во вкладке **Запросы**. Запрос можно привязать ко всем PostgreSQL-подключениям или одному профилю. Двойной щелчок открывает SQL в редакторе.

## Данные и перенос

Пользовательские профили, запросы, настройки и журнал создаются на каждом ПК отдельно в Electron `userData`. Они не входят в installer. Пароли не экспортируются. Для проверки на другом ПК создайте подключение заново.

## Ограничения MVP

- Одновременно выполняется один запрос из текущего редактора.
- Разрешён один SQL statement за запуск.
- PostgreSQL provider — единственный установленный provider.
- Installer без настроенного CI-сертификата будет показывать предупреждение Windows SmartScreen.
- Автоматическая установка обновления ещё отключена; проверка, подпись и безопасная загрузка уже реализованы.

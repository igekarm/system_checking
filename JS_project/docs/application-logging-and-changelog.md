# Журнал приложения, версия и changelog

## Журнал

Технические журналы desktop-приложения находятся в `%APPDATA%\DB Tools\logs`. Открыть каталог можно кнопкой **Настройки → Открыть папку логов**.

- `application.log` — текущий журнал;
- `application.previous.log` — предыдущая часть после достижения 5 МБ.

Журнал содержит запуск и завершение приложения, версию, этапы проверки/загрузки обновлений и HTTP-статусы публичного GitHub Releases API. Авторизация и токены GitHub не используются. SQL, результаты, параметры и секреты подключений не записываются.

## Подготовка описания новой версии

Перед созданием тега откройте корневой `JS_project/CHANGELOG.md` и добавьте сверху раздел с точной версией релиза:

```markdown
## 0.1.6

- Первое изменение.
- Второе изменение.
```

После установки релиза файл включается в приложение. При первом запуске каждой новой версии changelog показывается автоматически и больше не открывается после нажатия **Понятно**. Признак просмотра хранится в `%APPDATA%\DB Tools\application-state.json`.
